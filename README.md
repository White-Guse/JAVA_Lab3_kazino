# Lab3_kazino

Лабораторная работа по паттерну «Цепочка обязанностей».

Игра запускается из IntelliJ IDEA через класс `GameApplication` или командой:

```bash
mvn javafx:run
```

Игрок добавляет монеты, запускает автомат и выбирает один из трёх мешочков. Результат выбора проходит по цепочке обработчиков: выигрыш, проигрыш или бесплатная попытка.
